# Books-to-Scrape-and-EDA

Project Overview

This project focuses on collecting, cleaning, analyzing, and visualizing book data from the Books to Scrape website.

The dataset contains 1,000 books collected from 50 pages using Python web scraping techniques.

Dataset

* Title: Name of the book.
* Price: Book price in GBP (£).
* Rating: Customer rating from 1 to 5.
* Availability: Book availability status.

Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

Data Collection

* Collected data from 50 website pages.
* Extracted book titles, prices, ratings, and availability.
* Stored the collected information in a Pandas DataFrame.
* Exported the dataset to CSV format.

Data Cleaning

* Checked for missing values.
* Checked for duplicate records.
* Converted prices into numeric values.
* Converted ratings into integers.
* Cleaned availability text.

Exploratory Data Analysis (EDA)

* Statistical summary of book prices.
* Most expensive and cheapest books.
* Number of books by rating.
* Average price by rating.
* Book distribution by price range.
* Availability distribution.
* Relationship between book price and rating.

Data Visualization

* Bar Chart
* Horizontal Bar Chart
* Pie Chart
* Donut Chart
* Histogram
* Scatter Plot
* Box Plot
* Violin Plot
* Line Plot
* ECDF
* Dual Axis Chart

Project Structure

* books_scraping.ipynb – Web scraping, data cleaning, analysis, and visualization.
* books_dataset.csv – Collected dataset.
* insight.md – Analytical insights.

Data Source

* Books to Scrape

Project Goal

The main goal is to practice web scraping, data preparation, exploratory data analysis, and data visualization using Python.
